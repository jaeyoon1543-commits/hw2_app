기존 브라우저 데이터 내보내기

기존 앱을 사용하던 Live Server 주소에서 이 페이지를 열어주세요.
예: http://127.0.0.1:5500/legacy-export.html

localStorage는 주소마다 다르므로 기존에 사용했던 호스트와 포트가 같아야 합니다.

백업에는 사진과 글만 포함됩니다. 계정 비밀번호는 포함되지 않습니다. 기존 데이터는 삭제하지 않습니다.

내보낸 후 레시피 앱에서 회원가입·로그인하고 화면 하단의 ‘백업 가져오기’를 선택하세요. 기존 계정은 자동 이전되지 않습니다. 선택한 계정의 글과 계정 없이 작성한 레시피를 현재 로그인한 계정으로 가져옵니다.
