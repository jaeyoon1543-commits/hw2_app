# 한끼노트

한국어 레시피 공유 앱의 시제품입니다. VS Code Live Server로 `index.html`을 열어 실행합니다. 빌드는 필요 없습니다.

## 구현 기능

- 음식 이름·재료 검색, 요리 분류 필터, 조리시간 정렬
- 재료와 조리 단계 상세 보기
- 직접 만든 레시피 등록 및 원작자·출처를 포함한 다른 사람의 레시피 등록
- 레시피 북마크 및 저장 목록
- 레시피별 댓글과 1~5점 별점 등록, 평균 별점·평가 수 표시 (댓글 또는 별점만 등록 가능)
- 모바일 화면 지원
- 사진 보관함에서 선택하거나 지원되는 모바일 기기의 카메라로 촬영하여 요리 사진 등록, 미리보기·교체·삭제

요리 사진은 최대 20MB까지 선택할 수 있고, 긴 변 최대 1280px의 JPEG로 자동 축소해 레시피와 함께 이 브라우저에 저장합니다. 브라우저가 읽지 못하는 HEIC 등의 사진은 JPG/PNG로 변환 후 선택해주세요. 저장 공간이 부족하면 기존 레시피를 덮어쓰지 않고 오류를 표시합니다.

## 브라우저 계정 기능

- 아이디·닉네임·비밀번호로 회원가입하고 로그인합니다. 작성 시 닉네임을 다시 입력하지 않습니다.
- 별점과 댓글은 별도로 등록·수정·삭제합니다. 계정당 레시피별 별점과 댓글은 각각 하나이며, 별점은 평균 점수에만 반영되고 댓글 목록에는 댓글만 표시합니다. 댓글을 삭제해도 별점이 유지되며 별점을 삭제해도 댓글은 유지됩니다.
- 로그인한 계정으로 레시피를 등록하고 본인 레시피만 수정·삭제합니다. 내 레시피 목록도 계정별로 표시합니다.
- 비밀번호는 임의의 salt와 PBKDF2-SHA-256(210,000회)으로 해시하여 저장합니다. 로그인 세션은 현재 탭의 sessionStorage에 저장됩니다.
- Live Server의 localhost 주소에서 실행해주세요. Web Crypto가 필요합니다.
- 기존 계정 없는 글은 보존되지만 소유자를 확인할 수 없어 수정·삭제할 수 없습니다.

이 기능은 로컬 시제품입니다. 계정·작성자 권한 검사도 브라우저 안에서 수행하므로 개발자 도구로 우회할 수 있습니다. 실제 사용자 서비스에는 서버 인증, 서버에서의 작성자 권한 검사와 데이터베이스의 계정별 평가 중복 제약이 필요합니다. 다른 기기·브라우저와 계정이나 글을 공유하지 않습니다.

## 데이터

계정, 레시피, 댓글·평가와 북마크는 현재 브라우저의 localStorage에 저장됩니다. 브라우저 데이터를 지우면 삭제됩니다. 다른 기기나 사용자에게 공유되지 않습니다. 실제 다중 사용자 서비스에는 서버·데이터베이스·회원 인증과 사진 업로드를 연결해야 합니다.

초기 레시피는 시연용 예시입니다. 외부 사진은 Unsplash의 분위기용 이미지로 실제 조리 결과와 다를 수 있습니다. 사진과 웹폰트 로드에는 인터넷이 필요하며 사진 로드 실패 시 기본 이미지를 표시합니다.
